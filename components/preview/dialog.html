Native modal dialog, 50% overlay, color-border-strong edge, shadow-floating, focus containment and focus return. Not for production.

Open a dialog

The native <dialog> element opens with showModal(). The page behind it is inert, scroll is locked, and Escape closes it. Focus returns to the trigger.

No dialog open.

Behavior

  • Initial focus: first focusable element; the destructive dialog focuses Cancel.
  • Tab and Shift+Tab stay inside the dialog.
  • Escape, Close, and Cancel all return focus to the trigger.
  • Backdrop click does not close the dialog.
  • Dialog is fluid below 640px and keeps 24px viewport margins.
