# DabDesign

**Version:** 1.0.0 · 2026-11-14
**Entry point:** [`GUIDELINE.md`](GUIDELINE.md)

DabDesign is the shared design contract for DabAZ web projects: color ramps and
a thin semantic mapping, typography roles, space and shape, elevation and
motion, layout, icons, accessibility, and component status. It is a design
dependency repository, not a web application. It ships no framework, build
chain, CI, or deploy target.

## Read order

1. [`GUIDELINE.md`](GUIDELINE.md) — agent entry point: dependencies, read
   order, token use, breakpoints, component status.
2. [`core.md`](core.md) — the normative core contract. Its frontmatter is the
   only token block.
3. [`GOVERNANCE.md`](GOVERNANCE.md) — principles, `DEC-` decisions, and the
   site-theme contract.
4. [`DabDesign.md`](DabDesign.md) — the personal-series theme, for `dabaz.me`
   and DabResume only.
5. [`CHANGELOG.md`](CHANGELOG.md) — released changes.
6. [`ROADMAP.md`](ROADMAP.md) — post-1.0 work and open decisions.

[`AGENTS.md`](AGENTS.md) is the repository contract for agents and pins the
upstream dependencies.

## Normative and non-normative

| Path | Status |
|---|---|
| `GUIDELINE.md`, `core.md`, `GOVERNANCE.md`, `DabDesign.md` | Normative |
| `README.md`, `AGENTS.md`, `CHANGELOG.md`, `ROADMAP.md` | Repository metadata |
| `palettes/` | Generated evidence for the color contract |
| `references/third-party/` | Unofficial prior art; never a standard |
| `archive/` | Non-normative; kept only for comparison |

Everything in `archive/` belongs to the previous release. Do not use it as a
contract or copy its tokens, components, previews, or scripts into a project.

## Palette catalog

`palettes/catalog.md` and `palettes/ramps.json` are generated by
`scripts/hue-catalog.mjs`. The script also verifies every checked contrast pair
and exits non-zero on a failure.

```sh
node scripts/hue-catalog.mjs
```

To inspect the visual catalog, serve the repository root and open the preview:

```sh
python3 -m http.server 8000
```

Then open <http://127.0.0.1:8000/palettes/preview.html>.
