# DabDesign Roadmap

**Version:** 1.0.0 · **Updated:** 2026-11-14
**State:** released locally; not pushed. The normative contract is
`GUIDELINE.md`, `core.md`, and `GOVERNANCE.md`.

## Next

1. Run the official-site pilot with Button, Text input, and Card; add Dialog
   only if the pilot needs a modal.
2. Record real contrast and viewport results, including 320 px overflow, then
   review them with the Owner. Only the Owner promotes a component from Draft.
3. Decide whether the shared component contract earns its keep after the pilot;
   keep site-owned components out of the core.
4. Build the token exporter from the `core.md` frontmatter; keep `palettes/`
   generated by `scripts/hue-catalog.mjs`.
5. Add a second site theme when a second product needs one; do not fork the
   core.

## Open

- Bright light-theme accent fills and focus on tinted surfaces are unverified.
- No CI; `node scripts/hue-catalog.mjs` is the only automated check.
- The DabFonts `v1.0.0` tag must exist before consumers pin it.
- `archive/` is frozen and non-normative.
