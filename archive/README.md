# Archive

Everything under `archive/` is **non-normative**. It is kept only so the
previous system can be compared with the current one.

- Do not use it as a contract or as a reference implementation.
- Do not copy its tokens, components, previews, fonts, or scripts into a site.
- The normative files are `GUIDELINE.md`, `core.md`, and `GOVERNANCE.md` at the
  repository root.

| Path | Contents |
|---|---|
| `0.1.0/components/` | Six component drafts and their preview pages |
| `0.1.0/foundation/` | Foundation test page, transcribed CSS, and the Inter / Noto subsets |
| `0.1.0/backup-2026-11-10/` | Earlier `core.md` and `DabDesign.md` |
| `0.1.0/scripts/` | Retired palette generators |
